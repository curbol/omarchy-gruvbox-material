# Gruvbox Material — Omarchy Theme

An [Omarchy](https://omarchy.org) theme based on [gruvbox-material](https://github.com/sainnhe/gruvbox-material) by sainnhe, with orange accents.

## Palette

Uses the gruvbox-material **medium** background with **material** foreground variant.

| Role | Color |
|---|---|
| Background | `#282828` |
| Foreground | `#d4be98` |
| Accent / Cursor / Selection | `#e78a4e` (orange) |
| Red | `#ea6962` |
| Orange | `#e78a4e` |
| Yellow | `#d8a657` |
| Green | `#a9b665` |
| Aqua | `#89b482` |
| Blue | `#7daea3` |
| Purple | `#d3869b` |

## Includes

- **Neovim** — [sainnhe/gruvbox-material](https://github.com/sainnhe/gruvbox-material) with material foreground, orange menu selection, and transparent background
- **Terminal** — ghostty, kitty, alacritty (via colors.toml templates)
- **btop** — orange highlights
- **VS Code** — [Gruvbox-ish Medium](https://marketplace.visualstudio.com/items?itemName=GracefulPotato.gruvbox-ish)
- **Icons** — Yaru-olive
- **Waybar, Walker, Mako** — generated from palette

## Install

```bash
omarchy-theme-install https://github.com/curbol/gruvbox-material-omarchy
```

This installs the theme as `gruvbox-material` and applies it immediately.

To switch to it later:

```bash
omarchy-theme-set gruvbox-material
```
